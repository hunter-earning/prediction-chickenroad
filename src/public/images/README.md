Place your real images here. The app looks for these paths by default:

Folders
- app-logos/: logos for each app in the connection modal
- banners/: a wide header/banner image for the app header
- icons/: any small icons

Default filenames used by the app (replace these with your assets):
- app-logos/cr-original.svg
- app-logos/cr-plus.svg
- app-logos/feather-fire.svg
- app-logos/coop-x.svg
- banners/chicken-road.svg

You can change paths in `src/App.tsx` if needed.
